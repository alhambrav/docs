CrafterCMS Version 4.7.0 and 4.7.0E
-----------------------------------

Released *October TBD, 2026*

.. important::

    Please see :ref:`upgrade-notes-for-craftercms-4.7.0` for an important note and
    :ref:`Breaking changes <breaking-changes-4-x>` for breaking changes and other
    things to consider before upgrading

    For instructions on how to update your CrafterCMS install, please see :ref:`upgrading-craftercms`

^^^^^^^^^^^^
New Features
^^^^^^^^^^^^
* New basic ``users.properties`` file to support Engine authentication |br|
  See :ref:`engine-users-properties` for more information

* New configuration property ``studio.authoring.serverUrl`` for external/browser-facing Studio links. |br|
  See :ref:`studio-authoring-url` for more information

* New :base_url:`generatePreviewToken <_static/api/studio.html#tag/security/operation/generatePreviewToken>` API for
  generating preview tokens. The Token Management UI now uses this API instead of the general-purpose encryption API.
